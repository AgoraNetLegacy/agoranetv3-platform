AgoraNet publishes a known-issue notice when the same technical problem affects multiple users. Each notice names the affected feature, when the problem was first seen, any safe workaround, and whether it has been resolved.

No active incident is listed in this version. If the same action keeps failing, ask the helpdesk or open a support request so the operator can compare it with other reports.
