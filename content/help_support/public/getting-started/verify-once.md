You can read AgoraNet's account-creation and onboarding help without signing in. To create a profile or participate by posting, voting, or joining a group, start on the account setup page.

During setup, AgoraNet asks you to complete one human-verification check. When it succeeds, the site shows a one-time private code called a Humanity Credential. It proves that one person completed verification. Save it immediately. AgoraNet cannot display or recover it later.

Next, you create your True Self, which is your public AgoraNet profile. That profile receives a separate access key used to sign in. Save both codes somewhere private and reliable, and never send either code to Support.
