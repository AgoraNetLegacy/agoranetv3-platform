Open the account setup page in the same browser you used before. AgoraNet will carry forward any completed setup step. You do not need to remember the page's internal name, and Support will never ask you to reconstruct or share a private code that was shown once.

If you already created a profile and saved its access key, open Sign in instead of beginning again. If an access key appeared but you did not save it, do not create another profile or send any private code to Support. Read “Save your Humanity Credential and access key” before taking another action.
