# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately through [GitHub's security advisory form](https://github.com/projectpollify/agoranetv3-platform/security/advisories/new).

Please include the affected URL or component, reproduction steps, impact, and any relevant logs or screenshots. Do not include passwords, access keys, wallet seed phrases, or other secrets in a report.

We will acknowledge reports as soon as practical and coordinate disclosure after the issue is understood and a fix or mitigation is available.
